# Judge Q&A

**Is this live?** No. It is a historical issue-time replay prototype.

**Does it validate NCUM/NEPS?** No. The proposed MVP uses GEFSv12 reforecasts and IMD rainfall. NCUM/NEPS needs matched historical fields, retraining, calibration, and out-of-time validation.

**What is a bust?** A defined regional 24-hour rain error above a frozen train-only threshold, not an official IMD alert threshold.
