```python
def decode_gefs(key, bbox, variable):
    # Read actual inventoried GRIB key; filter India bounding box only after decoding.
    # Return member, init_utc, valid_time, step_start_h, step_end_h,
    # step_type, units, lat, lon, value, source_key. Reject missing metadata.
    ...

def exact_24h_total(records, start_utc, end_utc):
    # Verify nonoverlapping intervals exactly tile [start,end); reject gap/overlap.
    # For interval accumulation use interval amounts; for cumulative amounts
    # difference consecutive cumulative totals before summing. Never sum
    # overlapping cumulative GRIB fields. Normalize to mm.
    intervals = normalize_step_ranges(records)
    assert union(intervals) == (start_utc, end_utc)
    assert no_gap_or_overlap(intervals)
    return sum(x.mm for x in intervals)

def make_region_row(init, lead, region, imd_day, policy):
    start, end = policy.window_for(imd_day, init, lead)  # audited 03–03 or source-confirmed
    fc = exact_24h_total(control_records, start, end)
    obs = area_weighted_mean(imd_rain[imd_day], region.land_cells)
    coverage = valid_land_area / configured_land_area
    if coverage < 0.80 or fc is None or obs is None: return missing_row(reason=...)
    return row(init, lead, start, end, region, fc, obs, abs(fc-obs), provenance=...)

def fit_thresholds(train_rows):
    # Only 2010–15 rows; same region × JJAS/non-JJAS × (1–3,4–7,8–10).
    # Explicitly log sparse groups; predeclared wider-group fallback uses
    # train years only. Do not compute a threshold from validation/test rows.
    q90 = train_rows.groupby(['region_id','season','lead_bucket']).error_mm.quantile(.90)
    return maximum(q90, 10.0)  # mm/day material-error floor

def apply_labels(rows, frozen_thresholds):
    return rows.assign(threshold_mm=lookup(rows, frozen_thresholds),
                       bust=lambda x: (x.error_mm > x.threshold_mm).astype(int))
```

Use a fixed `regions_2deg.geojson`, longitude-normalized grid, land mask, area weights, explicit cell count and 80% area coverage (Reference §3). Freeze region IDs before training. Create `config/label_policy.yaml` with `floor_mm: 10`, `seasons: JJAS/other`, `lead_buckets: [[1,3],[4,7],[8,10]]`, `coverage_min: 0.80`, and the audited time-window mapping. Test 5/10/20-mm floors as sensitivity *after* the main policy is frozen. Separate missing data from no bust. `window_quality=approximate` must propagate to UI and evaluation exclusions. Do not interpolate a missing observation to create a label.

**Data QA deliverable:** `docs/data_audit.md` includes one source-file example for each provider, decoded grid/units, window diagrams, sample-level hand calculations, conservation checks, missingness by split/lead/season, and Day-10 verdict. ## 4. Explainability layer

**D owns, C reviews; start 28 Sep 12:00, complete by 29 Sep 10:00.** Compute `shap.TreeExplainer(model)` on the **raw LightGBM score** for each displayed case (Reference §5). Group feature contributions by an explicit file `config/reason_groups.yaml`: moisture, circulation, ensemble disagreement, analog-error memory, lead/season. Select the top 2–3 groups by absolute aggregate contribution and retain sign, feature value, train distribution range, raw-score base value and model/version. Do not pass raw SHAP log-odds off as a change in calibrated probability; show final `p_bust` separately, and caption the bars “contribution to model score.” The calibrated probability comes from the validation-fitted sigmoid.

`explain.py` returns a typed payload: `{region_id, init_utc, lead_day, p_bust, confidence_complement, reasons:[{group,direction,feature,value,train_range,caption,evidence_layer}], analogs:[{init_utc,lead_bucket,distance,forecast_mm,observed_mm,error_mm}], caveats}`. Template captions require the named forecast field and direction. A missing map/evidence layer gets a statistical-signal caption instead of a physical-cause assertion. If fewer than five qualified earlier analogs exist, return the ones available, `no_close_analog`, and the train climatology fallback; never duplicate cases to make five. F audits five displayed flags against input rows and checks that every analog `init_utc < query.init_utc` and observation is from a real IMD record. The UI calls these **model evidence**, not proven meteorological causes.
